1. تفاوت git add و git commit:
git add تغییرات را به Staging Area منتقل می‌کند، اما git commit تغییرات آماده‌شده را در تاریخچه مخزن ثبت می‌کند.

2. چرا فایل .env نباید commit شود؟
چون این فایل معمولاً اطلاعات محرمانه مانند رمزهای عبور و کلیدهای API را نگهداری می‌کند و نباید وارد مخزن شود.

3. تفاوت git diff و git diff --staged:
git diff تغییرات فایل‌های tracked را که هنوز stage نشده‌اند نشان می‌دهد، اما git diff --staged تغییرات stage‌شده را نسبت به آخرین commit نمایش می‌دهد.
